# Printly — Landing Page Comercial

Landing page estática pronta para GitHub Pages.

## Publicar no GitHub Pages

1. Crie/abra o repositório público.
2. Envie **o conteúdo desta pasta para a raiz do repositório**.
3. Confirme que `index.html` aparece na raiz, junto com `assets/`.
4. Vá em **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Branch: `main`.
7. Folder: `/ (root)`.
8. Clique em **Save**.

## Estrutura

- `index.html` — página principal
- `assets/css/styles.css` — identidade visual e responsividade
- `assets/js/main.js` — animações, galeria e lightbox
- `assets/img/` — logos oficiais e telas reais do Printly
- `.nojekyll` — evita processamento desnecessário pelo Jekyll
- `robots.txt` — indexação básica
