# Printly — Landing Page Comercial

Landing page estática pronta para GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie **o conteúdo desta pasta** para a raiz do repositório (não envie a pasta externa como um único nível adicional).
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)`.
6. Salve e aguarde a publicação.

## Estrutura

- `index.html` — página principal
- `assets/css/styles.css` — visual responsivo + animações
- `assets/js/main.js` — interações, galeria, lightbox, partículas
- `assets/img/` — logos oficiais e telas reais do Printly
- `.nojekyll` — compatibilidade com GitHub Pages
